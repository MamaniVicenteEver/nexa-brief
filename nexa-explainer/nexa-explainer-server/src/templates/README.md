Explainer: composiciones 16:9 para recortes editoriales, narración y capas de
postproducción.

Las plantillas heredadas de imágenes, letras y música fueron separadas en
`../legacy-templates/`. Siguen disponibles para los niches antiguos, pero no
forman parte de este catálogo.

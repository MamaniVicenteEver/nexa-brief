Texto del post · nivel alto

El Apolo 11 descendió entre alarmas. El 20 de julio de 1969, la computadora del Eagle se sobrecargó y mostró los códigos 1202 y 1201. NASA registró cinco alarmas durante el descenso propulsado.

El software reinició las tareas prioritarias y el control de misión autorizó continuar. El Eagle llegó a la Luna: detrás del alunizaje hubo decisiones humanas y un sistema preparado para recuperarse.

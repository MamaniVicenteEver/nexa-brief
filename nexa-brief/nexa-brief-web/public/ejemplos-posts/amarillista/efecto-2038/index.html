Texto del post · alto

El reloj de 32 bits se agota. El 19 de enero de 2038, después de las 03:14:07 UTC, algunas aplicaciones que guardan el tiempo Unix en 32 bits con signo no podrán representar el siguiente segundo.

La mayoría de las arquitecturas de glibc ya usa tiempo de 64 bits, y Ubuntu 24.04 LTS migró armhf. Aun así, un programa antiguo puede conservar el límite incluso sobre un kernel de 64 bits. Revisa aplicaciones y formatos de datos, no solo el procesador.

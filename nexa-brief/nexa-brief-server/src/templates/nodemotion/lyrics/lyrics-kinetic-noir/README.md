# Cinético Noir (`lyrics-kinetic-noir`)

Video de letras con tipografía cinética en blanco sobre azul casi negro. Cada frase cantada aparece en una composición distinta (barra, pila, cita, eco, subtítulo, marco, caja o resaltado), con tecleo, cortes en bandas, trazos de luz y humo generados.

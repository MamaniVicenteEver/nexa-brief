# Notas de dirección

La referencia muestra dibujo manual limpio, gestos legibles, pelo castaño, acento amarillo y auriculares. Para el caso de Juan se adapta a un adulto y al tema, cuidando la dignidad del personaje. Las hojas son ilustraciones reutilizables transparentes, con pocas poses por hoja para preservar resolución; se documentan posiciones y limitaciones reales. No copiar marcas ni afirmar que el personaje representa una persona real.

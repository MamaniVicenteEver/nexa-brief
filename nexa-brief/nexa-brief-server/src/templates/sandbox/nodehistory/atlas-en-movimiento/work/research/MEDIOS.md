# Medios documentales candidatos

Consulta: 3 de noviembre de 2026. **No se descargaron imágenes, videos ni audios.** Se consultaron fichas públicas y metadatos. Ningún candidato es generado con IA.

Las fichas de Commons se contrastaron mediante `imageinfo/extmetadata` y su texto de licencia; evidencia en `commons-fichas.json`, `commons-archivo.json` y `commons-archivo-extra.json`. `media.py search` se ejecutó para Stark, Jomeini y Sadam; para consultas poco precisas se amplió la búsqueda con la API de Commons. No se ejecutó `media.py get`.

## Descartes y pendientes concretos

- `File:Mohammad-Ali Rajai.jpg` aparece con **GFDL**: descartado por quedar fuera de las cuatro licencias pedidas. Se eligió P07.
- Las fotos IWM con **OGL** pueden tener condiciones de reutilización propias, pero no entran en la lista cerrada del brief. Se eligió un Hermes de U.S. Navy.
- Las fotos de daños del Bridgeton en la entrevista de Frank Seitz tienen autor privado identificado, pero no una licencia libre comprobada: **no se seleccionan como medios**. El artículo sí sirve como fuente histórica.
- No se seleccionó una foto libre y pertinente de la **refinería de Abadán bajo ataque en 1980**. La búsqueda devolvió imágenes de 1913, 1941, 1948 y 1970: no sirven para simular documentación del ataque. Dibujar `site.refinery` sobre el mapa.
- No se seleccionó una imagen del **Iran Air 655**. Si Claude decide incorporarlo, el hecho puede contarse con un rótulo y una ruta civil discreta, sin una explosión. Una eventual foto necesita otra búsqueda específica.
- Falta revisar visualmente originales y recortes; en esta fase solo se comprobó identidad declarada, fecha, resolución, autoría y licencia de las fichas. La descarga e incorporación quedan para la siguiente tarea autorizada.

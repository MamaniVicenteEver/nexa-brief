# Vista previa táctica

Esta entrada es la fuente pública para la galería del motor propio de Atlas en Movimiento. `demo.html` y sus tres auxiliares se extrajeron de `work/tactico/` conservando la misma profundidad y los imports hacia `../../engine/`; no se copiaron motor, sprites ni recursos de episodios. La nueva galería filtra el selector y `only` con el catálogo declarado, por lo que no vuelve a mostrar componentes retirados. Los originales bajo `work/` quedan temporalmente como respaldo histórico y no deben editarse para el Showcase.

La vista individual usa `?only=<componente>&aspect=9x16` o `aspect=16x9`. La disponibilidad HTTP depende de que el perfil tenga autorizados el diseño y su motor; esta carpeta no habilita acceso general a `work/` ni a otros episodios.

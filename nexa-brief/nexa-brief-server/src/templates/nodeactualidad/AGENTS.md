# NodeNews templates

Reusable NodeNews designs live here, grouped under the category's `folder` value from the active profile (`nodeactualidad`). The profile category ID is `node_actualidad`.

Keep reusable design source in this repository. A profile's demo or episode instance belongs under that profile's `productions/nodeactualidad/`; never copy profile-only work logs or generated results into this source package.

Generation engines remain shared in their existing engine directories. Cara a Cara uses `sandbox/nodeaction/_pizarra` and `sandbox/_proto`; do not duplicate or relocate those engines into a category design folder.

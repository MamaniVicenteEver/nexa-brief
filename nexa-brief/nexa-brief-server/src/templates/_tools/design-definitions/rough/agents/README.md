# Instrucciones del agente de ediciones

El mensaje se compone en este orden: rol global; instrucciones de edición de este diseño (`edition.md`, segundo párrafo del agente); persona y expresión del mercado; estrategias con sus capas nativas; ficha editorial de la historia; tarea y contrato de salida.

El agente recibe una tabla de textos con claves estables, el guion y la intención por segmento. Entrega textos, guion con los mismos identificadores y frases disparadoras exactas. La aplicación conserva la estructura visual y calcula después los tiempos. La voz y sus rutas se resuelven antes en la edición maestra.

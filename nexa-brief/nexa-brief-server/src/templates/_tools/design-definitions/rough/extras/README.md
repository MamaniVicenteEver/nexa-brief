# Auxiliares de pronunciación

Los léxicos contienen referencias editoriales para nombres y siglas. No se insertan en los rótulos ni sustituyen silenciosamente el guion. La edición resuelta incorpora su contenido para que las herramientas no lean capas. EN y PT son borradores: la elección de voz requiere una escucha futura; en esta tarea no se sintetiza audio.

Candidatas según el catálogo oficial de Gemini: Iapetus (clara), Orus (firme), Sadaltager (informada). Fuente consultada el 12-11-2026: https://ai.google.dev/gemini-api/docs/speech-generation .

# Etapa — analizar el diálogo y proponer imágenes

Lee el relato y extrae, en orden, cada imagen que el oyente imagina. Para cada una, entrega:
- Fragmento del relato y qué se debe ver exactamente, y qué no.
- Consulta de búsqueda propuesta.
- Criterio de impacto visual: encuadre apropiado al asunto, luz expresiva, resolución adecuada, sin marcas de agua ni elementos que distraigan. Un paisaje puede pedir una vista amplia; un producto, un detalle sensorial. No impongas paisajes a todas las campañas.
- Permanencia sugerida. Abre con la imagen que mejor materialice la promesa y dale tiempo para atrapar al espectador.
- Texto breve y legible que explique una condición real si no se expresa en la voz.

Si ninguna imagen encontrada cumple lo contado, vuelve al texto; no fuerces la imagen. Distingue búsquedas propuestas, medios encontrados y medios seleccionados. En esta prueba solo se planifica: no se descargan medios, no se sintetiza voz ni se crea video.

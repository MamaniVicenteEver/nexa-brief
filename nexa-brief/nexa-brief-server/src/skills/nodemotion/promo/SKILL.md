## Específico de esta skill

# NodeMotion promo

Use the shared [production guide](../../../templates/_tools/nodemotion/promo/production/GUIDE.md), [operator guide](../../../templates/_tools/nodemotion/promo/production/OPERATE.md), and [quality policy](../../../templates/_tools/nodemotion/promo/production/QUALITY.md).

All implementation, versioned prompts, contracts and production tools are owned by the NodeMotion module. Projects contain data and resource references; never copy an engine into a video. Preserve stable identifiers and all visual behavior.

For creating a reusable promo template, use [template authoring](../../../../docs/nodemotion-template-authoring.md). This skill prepares campaigns of existing designs; it does not register a design.

# Pruebas de personas y medios

La prueba busca **Alan Turing** y **Neil Armstrong** usando los 13
proveedores de `researcher_data`. Para cada persona intenta conservar seis
imágenes y cuatro vídeos.

Los candidatos no se toman por posición. Se puntúan por coincidencia con el
nombre y alias, descripción, licencia, proveedor, tipo de medio y diversidad de
fuentes. Cada persona tiene su propio `resultados.json` y carpetas de medios.

`videos` son archivos descargados y validados; `videos_referencias` son enlaces
de catálogo sin archivo directo y no se cuentan como descargas.

# nexa-brief (monorepo)

El proyecto principal está en **[`nexa-brief/`](nexa-brief/README.md)**: API (`nexa-brief-server`) y panel web
(`nexa-brief-web`). Para empezar:

```bash
cd nexa-brief
make setup
make dev
```

Otras carpetas:

| Carpeta | Qué es |
| --- | --- |
| `nexa-academy/`, `nexa-explainer/` | Proyectos hermanos derivados de nexa-brief |
| `nexa-render/` | Variante de render con diseño dinámico |
| `nexa-docs/` | Documentación e investigaciones |
| `html-templates-poc/`, `nexa-brief-web-scraping/` | Pruebas de concepto |
| `nexa-branding/` | Marca |
